# 续忆 1.0.4 更新说明

安装方式不变。升级后旧档案、日记、人设都照常能用。

## 首次引导：扫码要扫两次，现在写清楚了

- 第一次用手机 QQ 扫码，只是在手机上建好机器人；建好后要在手机上点「扫码连接」，再扫一次电脑上同一个码，才算绑上。以前引导只写了扫一次，很多人建完机器人以为卡住了。
- 扫完码一直停在「扫码成功，正在连上机器人」时，提示提前到 20 秒出现，并且分情况说：
  - 机器人信息已经存好了：只差 DSH 重新加载，把 DSH 完全退出（托盘图标也退掉）再打开就好，不用重新扫码；
  - 没存进去：重新扫一次码（有时是杀毒软件或网盘同步占着文件）。
- 扫码时切去别的页面再回来，等待时间不会从头算。

## 她更像同一个人

- 问她的老家、年纪、工作、学校、家里人，会把她以前的回答递给她，前后说法一致，不会每次换一个。

## 记忆更准

- 问「还记得上次那家烤肉店吗」「那本书你忘了没」这类问她记不记得的话，句子里没有「我」也会去翻旧事。
- 体重这类会变的数字（「我 120 斤」→「最近瘦到 110 了」），会把新旧两句一起找出来，并以新的为准。
