# 续忆 1.0.3 更新说明

安装方式不变。升级后旧档案、日记、人设都照常能用。

## 更安全：只有 DSH 自己的页面能打开续忆

- 续忆的日记本、TA的记忆、设置和首次引导，现在都要先通过 DSH 自己的登录检查才能打开。
- 以前只检查「是不是本机」，你浏览器里别的网页如果知道端口，有可能读到日记和记忆；现在没有 DSH 登录凭证的请求一律拒绝，冒充别的网站发来的请求也会被拦下。
- 在 DSH 里打开续忆的用法不变，不用做任何设置。

## 首次引导：卡住时告诉你怎么办

- 一键装 QQ 机器人插件超过一分半还没装好，会直接提示：把 DSH 完全退出（右下角托盘图标也退掉）再打开，或者去「插件 → 添加插件」手动装。
- 手机 QQ 扫完码后，会显示「扫码成功，正在连上机器人」（以前误写成「二维码马上就好」）。
- 扫码后 45 秒还没连上机器人，会提示完全退出 DSH 再打开，还不行就重新扫一次码。

## 主动查记忆更准

- 问「大学室友」这类问题时，不会把只是碰巧排在前面、其实不相干的话（比如在北京读研的同桌）也带进来。
